## 🚀 Featured Projects

### ♟️ Multiplayer Chess Game

**Tech Stack:** React.js · Node.js · Express.js · WebSockets

A real-time multiplayer chess platform built around WebSocket-based communication and concurrent game-session handling.

- ⚡ Real-time move synchronization over WebSockets with server-side move validation
- 🎯 Matchmaking system with isolated, independent game rooms
- 🧵 Modular backend separating matchmaking, game processing, and real-time communication
- 🔄 Event-driven architecture for game-state management and synchronization
- 🧪 Load-tested locally with 50+ concurrent matches and 5,000+ simulated moves, averaging under 100ms synchronization latency

### 📂 Project Management / Version Control Platform

**Tech Stack:** React.js · Node.js · Express.js · MongoDB

- 🔐 JWT authentication with bcrypt password hashing
- 📁 Repository management with public/private visibility and repository search
- 🐛 Issue tracking and user profile system
- 🧰 RESTful backend APIs on a MongoDB/Mongoose data layer, with a React dashboard
- 💻 Custom Git-like CLI supporting init, staging, commits, push/pull, commit history, and commit reversion via Node.js filesystem operations
